# Cyber Racer 80s

Um jogo de corrida retrô estilo OutRun/Retrowave feito em HTML5, CSS e JavaScript.

## Funcionalidades
- Gráficos pseudo-3D em Canvas 2D
- Física de condução suave e ajustável
- Suporte a toque para dispositivos móveis
- Sintetizador de áudio Web Audio API
- HUD completo com tempo, velocidade, nitro e pontos
- Modo dia/noite com efeitos visuais
- Espelho retrovisor com alerta de colisão traseira

## Como jogar
- Acelerar: Tecla ↑ / Botão ACE no mobile
- Frear/Desacelerar: Tecla ↓ / Botão FRE no mobile
- Direção: Teclas ←/→ ou A/D / Botões ◀/▶ no mobile
- Nitro: Barra de espaço / Botão ⚡ no mobile
- Pausar: ESC

## Controles Mobile
- Toque nos botões na parte inferior da tela
- Suporte a multi-toque (acelerar e virar ao mesmo tempo)

## Tecnologias
- HTML5 Canvas
- CSS3 (gradientes, blur, animações)
- JavaScript puro (sem bibliotecas externas)
- Web Audio API para som procedural
