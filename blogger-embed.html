Cyber Racer 80s (Car Sunset)

Um jogo de corrida retrô estilo OutRun/Retrowave feito em HTML5, CSS e JavaScript.

Funcionalidades

  • Gráficos pseudo-3D em Canvas 2D estilo arcade clássico
  • Física de condução suave e controlável
  • Suporte completo a toque para dispositivos móveis
  • Sintetizador de áudio Web Audio API (sem arquivos externos)
  • HUD completo com tempo, velocidade, nitro e pontos
  • Espelho retrovisor com alerta visual de colisão traseira

Como Jogar

  • Acelerar: Tecla ↑ / Botão ACE
  • Frear: Tecla ↓ / Botão FRE
  • Direção: Teclas ←/→ ou A/D / Botões ◀/▶
  • Nitro: Barra de Espaço / Botão ⚡
